ROLE: Software Engineer at Google (SWE)

OVERVIEW:
A Software Engineer at Google designs, develops, tests, deploys, and maintains large-scale software solutions. Google hiring emphasizes strong Computer Science fundamentals, data structures, algorithms, system design, and coding efficiency over specific framework knowledge.

CORE COMPETENCIES & HIRING BAR:
- Data Structures & Algorithms: Graphs (BFS/DFS), Dynamic Programming, Trees, Tries, Heaps, Hash Tables, Matrix Operations.
- Problem Solving & Complexity: Time and space complexity analysis (Big-O notation), edge case handling, clean code syntax.
- System Design (L4+ / Senior Roles): Distributed systems, CAP theorem, caching strategies (Redis/Memcached), database sharding, API design, load balancing.
- Googliness & Leadership: Handling ambiguity, psychological safety, collaborative problem solving, STAR interview method.

INTERVIEW PROCESS & STRATEGY:
1. Resume Screening & Referral: Must use Google's X-Y-Z formula ("Accomplished X, measured by Y, by doing Z").
2. Technical Phone Screen (45 mins): 1-2 algorithmic problems solved live on Google Docs/CoderPad.
3. Onsite Interview Loop (4-5 rounds): 3 Coding/Algorithm rounds, 1 System Design round, 1 Googliness & Leadership round.

PORTFOLIO & PREPARATION STRATEGY:
- Practice 150+ LeetCode Medium/Hard problems across core patterns (Two Pointers, Sliding Window, Graph Traversals, Backtracking).
- Build high-throughput, distributed backend projects (e.g., custom key-value store, distributed rate limiter, or open-source PRs).
